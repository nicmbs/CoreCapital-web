# CoreSolutions hero orb assets

## Look we want
A real 3D looping clip — metallic / glass object floating and morphing in space
(same category as [Dreamstime 417131417](https://www.dreamstime.com/abstract-metallic-object-floating-space-looping-animation-smooth-reflective-surface-video417131417)).

## How to plug it in
1. License / download a looping MP4 or WebM (black background preferred).
2. Save as:
   - `orb-live.webm` (preferred), and/or
   - `orb-live.mp4`
3. Refresh `/coresolutions` — `CSAiOrb` auto-detects the video and plays it muted/looped.
4. Black plate is removed in the UI with `mix-blend-mode: screen`.

Until a video file is present, the page falls back to `orb-live.webp`.
